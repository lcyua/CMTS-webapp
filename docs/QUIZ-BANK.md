# 스프레드시트 문제은행 사용

이 기능은 소스와 비공개 검토 화면에 준비한 상태이며 실서비스 Hosting에는 아직 반영하지 않았습니다. 검토 후 최종 배포합니다.

스프레드시트는 교사용 비공개 문제은행으로 유지하고, 실제 출제 문제는 홈페이지의 교사 편집 화면에서 검토한 뒤 저장합니다. 학생 브라우저가 정답이 들어 있는 원본 시트를 직접 읽거나 공개 링크를 조회하는 방식은 사용하지 않습니다.

1. 교사 ‘문제풀이’ 또는 설정의 ‘일일 문제’에서 ‘스프레드시트 문제은행에서 가져오기’를 엽니다.
2. ‘CSV 템플릿 다운로드’를 기준으로 원본 시트를 작성합니다. Google Sheets는 `파일 → 다운로드 → 쉼표로 구분된 값(.csv)`, Excel은 `CSV UTF-8`로 저장합니다.
3. CSV를 선택하면 유효한 문제와 오류 행을 검토할 수 있습니다. 파일 선택·미리보기만으로 서버에 저장하거나 출제하지 않습니다.
4. 문제 하나를 선택하고 오늘 이후의 출제 날짜를 확인합니다. ‘선택한 문제를 새 초안으로 불러오기’를 누르면 기존 문제를 덮어쓰지 않는 새 편집 초안이 됩니다.
5. 새 초안의 문제·보기·정답·해설을 확인합니다. 출제하려면 ‘사용 중’을 켠 뒤 기존 ‘저장’ 버튼을 누릅니다. ‘사용 중’을 끈 채 저장하면 비활성 문제로 보관됩니다.

| 머리글 | 입력 |
|---|---|
| 날짜 | `YYYY-MM-DD` 또는 빈칸. 지난 날짜의 문제는 새 출제 날짜를 선택해 재사용합니다. |
| 문제 | 필수, 2,000자 이하 |
| 보기1·보기2·보기3·보기4 | 각각 필수, 1,000자 이하 |
| 정답 | 보기 번호 `1`~`4` |
| 해설 | 선택, 4,000자 이하 |

한 번에 최대 200문제·1MB를 읽습니다. 쉼표·따옴표·줄바꿈이 포함된 셀은 스프레드시트의 CSV 내보내기 기능이 처리합니다. 머리글 순서는 바꿔도 되지만 8개 항목은 모두 필요합니다. `date, question, option1, option2, option3, option4, answer, explanation`도 허용합니다. ID·버전·발행 여부 등 추가 열은 허용하지 않습니다.

파일은 브라우저 메모리에서만 검토하며 별도 저장소에 자동 보관하지 않습니다. ‘불러온 파일 비우기’ 또는 해당 편집 화면을 떠나면 다시 파일을 선택해야 합니다. 원본 파일도 교사만 접근할 수 있는 장소에 보관합니다.

기존 서버 규칙은 그대로 적용됩니다. 하루에 활성 문제는 하나이며, 학생 제출이 시작됐거나 지난 날짜의 기존 문제는 내용·정답을 바꾸지 못합니다. 날짜별 문제를 자동으로 대량 출제하거나 원본 시트와 실시간 동기화하지 않습니다. 학생에게는 기존 인증·권한 검사를 거쳐 공개할 문제만 전달합니다.
